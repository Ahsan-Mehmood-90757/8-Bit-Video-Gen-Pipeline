# Pipeline V3: Visual-First (no voice, no captions)

V3 removes the TTS narrator and the spoken captions. The video is carried by three things instead:
- **motion**
- **impact micro-text**: 2–5 word pixel badges stuck to the moving parts
- **frame-locked 8-bit audio**: sound effects plus a rhythmic pulse/bass groove, at full volume with no ducking under a voice

v2 is untouched. Its folders (`engine/`, `pipeline/`, `templates/episode`) still work exactly as before, so you can compare v2 and v3 renders side by side. V3 *reuses* the v2 core read-only (pixel engine, camera, cutaways, arrows, HUD) and adds its own layers on top.

```
engine_v3/
  sim_base_v3.html      host page: v2 core + the v3 layers below
  micro_text.js         impact micro-text, hook banner, payoff stamp, beat clock
  safe_zone_v3.js       UI-safe box (90..920 x 260..1480), fitBoundsToSafeZone, per-frame QA tracking
  synth_engine.js       preview audio: master chain, 3-voice cap, C-major pentatonic <= 880 Hz
  audio_events_v3.js    logSfxV3 / logSynthStateV3 / logBeatPulseV3 (v2's R.sfx and R.hum are routed here)
  sfx_presets_v3.js     kick, bass, hat, snare + pop, hop, wrap, warn, stamp, evict, hit, swoosh, banner
pipeline_v3/
  render_v3.py          T timeline → B frames → C mix_v3.wav → E encode  (no TTS, no Whisper, no .ass)
  synth_v3.py           hits + filter-swept continuous voices + beat pulses + groove → lookahead limiter
  new_episode_v3.py     scaffold from templates/episode_v3 (standalone, or inside a channel)
episodes_v3/
  test_ring_buffer_v3/  pipeline test episode (28 s)
```

## script.json (v3)

```json
{
  "title": "Ring Buffer", "pipeline": "v3", "duration": 34,
  "beats": [
    { "id": "hook",    "start": 0,  "end": 4,  "cue": "...", "micro": "SHIFT ×6 · ZERO SHIFTING" },
    { "id": "core",    "start": 4,  "end": 16, "cue": "..." },
    { "id": "failure", "start": 16, "end": 26, "cue": "..." },
    { "id": "payoff",  "start": 26, "end": 34, "cue": "..." }
  ],
  "groove": { "bpm": 120, "steps_per_beat": 4, "start": 4, "end": 33,
              "pattern": { "kick": "x...x...x...x...", "hat": "..o...o...o...o.", "bass": "x.......x...x..." },
              "notes": ["A1", "A1", "F1", "G1"] },
  "mix": { "groove": 0.4, "pulses": 0.8, "sfx": 1.0, "synth": 1.0 }
}
```

- **Beats** are fixed time ranges. There's no narrator to pace them.
- **Pattern characters:** `X` is a hard hit, `x` normal, `o` soft, `.` rest.
- **`groove`** is optional. Remove it for a video with sound effects only.

## V3 toolkit (in addition to everything from v2)

| Call | What it does |
|---|---|
| `R.hookBanner(text, {t0, dur, sub, color})` | Slam-in banner for the first ~3 s (plays a `banner` sound automatically) |
| `R.micro(text, x, y, {t0, dur, style, color, size, at, pointer, anim, priority})` | 2–5 word badge anchored to a part (world coordinates inside `R.world`). Styles: `badge`, `ok`, `warn`, `tag`, `stamp`, `formula`. Pops in, fades out, and is laid out automatically so it never overlaps other text and stays inside the safe zone. |
| `R.formula(text, x, y, {t0, dur})` | Typewriter formula flash, e.g. `HEAD=(HEAD+1)%8` |
| `R.payoffStamp(text, {t0, color, y, sub})` | End-card stamp with a slam, shake, burst and `stamp` sound |
| `R.reserve(rect)` | Keeps micro-text and labels off a HUD element or pointer tag |
| `R.onBeat(div)` | True on the exact frame of each beat (or ½, ¼ beat). Uses the same frame math as the groove in `synth_v3.py`, so a mechanical step and its sound land on the same frame. |
| `R.pulse(kind, {note, accent, pan})` | Kick, bass, hat or snare accent on this frame |
| `R.synth(voice, {freq, duty, gain, noise, cutoff, res, wave, pan})` | Continuous voice whose pitch **and low-pass filter** follow the simulation. Call it every frame; it fades out when you stop calling it. |
| `R.SAFE` | The UI-safe box, `{x:23, y:65, w:207, h:305}` at low resolution (see below) |
| `fitBoundsToSafeZone(w, h, zoom)` | Largest zoom ≤ `zoom` at which a world box of size w×h fits inside the safe box |
| `Camera.track([{t, fit:[x,y,w,h], zoom}])` / `Camera.fitTo([x,y,w,h], {zoom, dur})` | Camera framing with the zoom automatically capped so that box stays fully visible |
| `R.node(x, y, w, h, label)` | Declares an "active node" (a gear, piston or packet drawn with polygons/circles). QA fails if it ever leaves the safe box. |
| `R.inView(x, y, w, h)` | True if a world box is fully inside the camera view |

## UI-safe zone (mandatory)

Everything must stay inside **x 90..920, y 260..1480** on the 1080×1920 frame. This leaves room for the Shorts/Reels buttons on the right, the header at the top and the title bar at the bottom. Note that the right margin (160 px) is wider than the left (90 px), so V3 centres its banner and stamp on the safe zone, not on the screen.

- **Labels:** micro-text, labels, hook banner, payoff stamp and pointer tags are clamped inside the box, including during their pop and shake animations.
- **Camera view:** it defaults to the safe box, so world drawing is clipped to it. Use `fit` keyframes or `fitBoundsToSafeZone()` so a zoomed-in array is never cut off.
- **Cut-off elements:** world text and boxes that would be cut by the view edge are not drawn at all. Zooms show only whole nodes, and those hidden elements are listed in the report.
- **QA check:** `--preview-only` tracks every text box, box, tag, micro-text and `R.node()` on **every frame**. If anything extends outside the box, QA **fails** (exit code 2), the offenders are outlined in magenta on the QA PNGs, and `qa/safe_zone_report.json` lists them with time, position and overflow. A faint magenta dashed border shows the box on the QA PNGs only; final renders never draw it.

## Musical audio mastering

The live preview (`engine_v3/synth_engine.js`, Web Audio) and the final MP4 soundtrack (`pipeline_v3/synth_v3.py`) apply the same rules:

1. **Signal chain:** `voiceGain (max 0.16)` → `lowpass 2000 Hz, Q 0.8` → `compressor (threshold −18 dB, knee 12, ratio 12, attack 3 ms, release 150 ms)` → `masterGain 0.75`.
2. **Polyphony:** a strict 3-voice cap per bus (sound-effects bus and rhythm bus). When a 4th voice starts, the oldest fades out in 15 ms. Rhythm has its own bus so effects never cut the beat.
3. **Notes:** every pitched sound is snapped to **C major pentatonic** and shifted down by whole octaves until its highest note is ≤ 880 Hz. Arpeggios keep their shape. Square and saw waves become warm triangles (≥ 200 Hz) or low filtered pulses. Noise percussion is unchanged.
4. **Final loudness (MP4 only):** the chain above is deliberately quiet (the test mix came out at −33.6 LUFS). Stage C applies one clean gain to −14 LUFS, then the lookahead limiter holds peaks at −1 dBFS. This avoids FFmpeg's pumping "dynamic" loudness mode.

To customise, add an `"audio"` block to `script.json`, e.g. `{"musical": false}` to keep raw 8-bit pitches, `{"polyphony": 4}`, `{"lufs": -16}`, or `{"lowpassHz": 3000}`.

**Verified on `test_ring_buffer_v3`:**
- highest note 880 Hz
- 0.23% of energy above 2.5 kHz
- hits within 2 ms of their frame (filter delay plus a 2 ms attack, well inside one 16.7 ms frame)
- final MP4 at −14.0 LUFS with peaks at −0.9 dBFS
